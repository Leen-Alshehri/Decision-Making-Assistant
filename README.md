# Smart Decision-Making Assistant

A lightweight Streamlit app that helps you make better decisions.  
Rank your criteria, enter options, and let the app score them using **Rank-Sum weights** with the **Weighted Sum Model (Simple Additive Weighting)**.


## Features
- Add and reorder decision criteria (from most to least important).
- Auto-assigned normalized weights based on priority.
- Rate options (0–10) for each criterion.
- Final weighted scores with a highlighted comparison table.
- Bar chart visualization of scores.
- “What-if” mode to experiment by changing weights or ratings.
